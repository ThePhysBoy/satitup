## คำแนะนำ
1. รูปภาพควรมีคุณภาพสูง แต่ขนาดไฟล์ไม่ควรใหญ่เกินไป (ไม่เกิน 500KB ต่อรูป)
2. ใช้รูปแบบไฟล์ JPG สำหรับภาพถ่าย และ PNG สำหรับโลโก้หรือภาพที่ต้องการความโปร่งใส
3. ควรใช้ชื่อไฟล์ภาษาอังกฤษ ไม่มีช่องว่างหรืออักขระพิเศษ
