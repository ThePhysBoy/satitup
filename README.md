# เว็บไซต์โรงเรียนสาธิตมหาวิทยาลัยพะเยา
## Demonstration School of University of Phayao Website

เว็บไซต์ทางการของโรงเรียนสาธิตมหาวิทยาลัยพะเยา พัฒนาด้วย PHP และออกแบบด้วยธีมสีม่วงอ่อนสดใสที่เหมาะสมกับนักเรียนระดับมัธยมศึกษา

## 🎨 คุณลักษณะเด่น

- **ดีไซน์ทันสมัย** - ใช้ธีมสีม่วงอ่อนที่สดใสและเป็นมิตรกับนักเรียน
- **Responsive Design** - รองรับการแสดงผลบนทุกอุปกรณ์
- **โครงสร้าง PHP Modular** - แยกส่วนประกอบเป็นไฟล์ต่างๆ เพื่อง่ายต่อการบำรุงรักษา
- **Slideshow อัตโนมัติ** - เปลี่ยนภาพทุก 5 วินาที
- **MathJax Support** - รองรับการแสดงผลสมการคณิตศาสตร์ LaTeX/MathML
- **Bootstrap 5** - ใช้ Framework CSS ที่ทันสมัย
- **Font Awesome Icons** - ไอคอนสวยงามครบครัน


## 🚀 การติดตั้งและใช้งาน

### ข้อกำหนดเบื้องต้น
- XAMPP หรือ Web Server ที่รองรับ PHP 7.4 ขึ้นไป
- MySQL/MariaDB (สำหรับฐานข้อมูลในอนาคต)
- Web Browser ที่ทันสมัย (Chrome, Firefox, Safari, Edge)

### ขั้นตอนการติดตั้ง

1. **คัดลอกไฟล์โครงการ**
   ```bash
   คัดลอกโฟลเดอร์ satitup ไปยัง C:\xampp\htdocs\
   ```

2. **เปิด XAMPP**
   - Start Apache
   - Start MySQL (หากต้องการใช้ฐานข้อมูล)

3. **เปิดเว็บไซต์**
   ```
   เปิด Browser แล้วไปที่: http://localhost/satitup/
   ```

## 🔧 การปรับแต่ง

### เปลี่ยนสีธีม
แก้ไขตัวแปร CSS ในไฟล์ `css/style-school.css`:
```css
:root {
    --primary-color: #8B7AA8;    /* เปลี่ยนสีหลักที่นี่ */
    --secondary-color: #9C89B8;   /* เปลี่ยนสีรองที่นี่ */
}
```

### เปลี่ยนเวลา Slideshow
แก้ไขในไฟล์ `slideshow.php`:
```html
data-bs-interval="5000"  <!-- เปลี่ยนเป็น milliseconds ที่ต้องการ -->
```

   - ตรวจสอบ Input Validation
