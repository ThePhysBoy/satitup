# คำแนะนำการแก้ไขปัญหารูปภาพสไลด์โชว์

หากพบปัญหารูปภาพสไลด์โชว์ไม่แสดง ให้ดำเนินการตามขั้นตอนต่อไปนี้:

## 1. แก้ไขเส้นทางรูปภาพในฐานข้อมูล

เข้าไปที่ URL: `/admin/fix_image_paths.php`

สคริปต์นี้จะแก้ไขเส้นทางรูปภาพในฐานข้อมูลให้ถูกต้อง โดยเปลี่ยนจาก `uploads/...` เป็น `admin/slideshow/uploads/...`

## 2. คัดลอกรูปภาพไปยังโฟลเดอร์ที่ถูกต้อง

เข้าไปที่ URL: `/admin/slideshow/copy_images.php`

สคริปต์นี้จะ:
1. คัดลอกรูปภาพจาก `admin/slideshow/uploads/...` ไปยัง `images/slideshow/...`
2. อัปเดตเส้นทางในฐานข้อมูลเป็น `images/slideshow/...`

## 3. อัปโหลดรูปภาพใหม่

หลังจากแก้ไขเส้นทางแล้ว การอัปโหลดรูปภาพใหม่จะบันทึกเส้นทางที่ถูกต้องโดยอัตโนมัติ

## หมายเหตุ

- หากยังพบปัญหา ให้ตรวจสอบสิทธิ์การเขียนไฟล์ในโฟลเดอร์ `images/slideshow/`
- ตรวจสอบว่าโฟลเดอร์ `images/slideshow/` มีอยู่จริง
- ตรวจสอบการเชื่อมต่อฐานข้อมูล
