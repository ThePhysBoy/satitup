# ระบบจัดการบุคลากร

## 📋 ภาพรวม
ระบบจัดการบุคลากรสำหรับโรงเรียนสาธิตมหาวิทยาลัยพะเยา ใช้สำหรับจัดการข้อมูลบุคลากรทั้งสายวิชาการและสายบริการ

## 🚀 คุณสมบัติ
- ✅ เพิ่ม/แก้ไข/ลบข้อมูลบุคลากร
- ✅ จัดการรูปภาพบุคลากร
- ✅ จัดการตำแหน่งหลายตำแหน่งต่อคน
- ✅ แบ่งประเภทบุคลากร (สายวิชาการ/สายบริการ)
- ✅ ค้นหาและกรองข้อมูล
- ✅ แสดงผลแบบแบ่งหน้า

## 📁 โครงสร้างไฟล์

## 🗄️ ฐานข้อมูล
### ตาราง `departments`
- `id` - รหัสแผนก
- `name` - ชื่อแผนก/หน่วยงาน
- `description` - คำอธิบาย
- `type` - ประเภท (academic/support/primary)
- `order_number` - ลำดับการแสดงผล

**ประเภทบุคลากร:**
- `academic` - สายวิชาการ (กลุ่มสาระวิชาต่างๆ)
- `support` - สายสนับสนุน (หน่วยงานสนับสนุน)
- `primary` - ประถมศึกษา (ชั้นเรียนประถม)

### ตาราง `staff`
- `id` - รหัสบุคลากร
- `title` - คำนำหน้าชื่อ
- `first_name` - ชื่อ
- `last_name` - นามสกุล
- `department_id` - รหัสแผนก
- `image_path` - ที่อยู่รูปภาพ
- `email` - อีเมล
- `phone` - เบอร์โทรศัพท์
- `education` - ประวัติการศึกษา
- `bio` - ประวัติและผลงาน
- `is_head` - เป็นหัวหน้าหรือไม่
- `order_number` - ลำดับการแสดงผล
- `status` - สถานะ (active/inactive)

### ตาราง `staff_positions`
- `id` - รหัสตำแหน่ง
- `staff_id` - รหัสบุคลากร
- `position_name` - ชื่อตำแหน่ง
- `is_primary` - เป็นตำแหน่งหลักหรือไม่

## 🔧 การติดตั้ง

### 1. ตรวจสอบระบบ
เปิด `http://localhost/satitup/admin/staff/system_check.php`

### 2. เพิ่มข้อมูลตัวอย่าง (ถ้าต้องการ)
เปิด `http://localhost/satitup/admin/staff/add_sample_data.php`

## 🎯 การใช้งาน

### สำหรับผู้ดูแลระบบ (Admin)
1. **จัดการบุคลากร**: `http://localhost/satitup/admin/staff/index.php`
2. **เพิ่มบุคลากรใหม่**: `http://localhost/satitup/admin/staff/create.php`
3. **แก้ไขข้อมูล**: คลิกปุ่มแก้ไขในหน้ารายการ
4. **ลบข้อมูล**: คลิกปุ่มลบในหน้ารายการ

### สำหรับผู้ชมทั่วไป (Frontend)
1. **ดูรายชื่อบุคลากรทั้งหมด**: `http://localhost/satitup/staff/index.php`
2. **บุคลากรสายวิชาการ**: `http://localhost/satitup/staff/academic.php`
3. **บุคลากรประถมศึกษา**: `http://localhost/satitup/staff/primary.php`
4. **บุคลากรสายสนับสนุน**: `http://localhost/satitup/staff/service.php`

## 🔐 สิทธิ์การเข้าถึง
- **Admin** (admin01): สามารถจัดการบุคลากรได้ทั้งหมด
- **PR Officer**: สามารถจัดการบุคลากรได้
- **ผู้ใช้ทั่วไป**: ดูข้อมูลได้อย่างเดียว

## 📝 หมายเหตุ
- รูปภาพบุคลากรจะถูกเก็บในโฟลเดอร์ `uploads/staff/`
- ถ้าไม่มีรูปภาพจะแสดงรูป placeholder จาก `assets/img/user-placeholder.png`
- ระบบรองรับไฟล์รูปภาพประเภท JPEG, PNG, WEBP ขนาดไม่เกิน 5MB
- **อัพเดตสำคัญ:** เปลี่ยนชื่อจาก "สายบริการ" เป็น "สายสนับสนุน" และเพิ่ม "ประถมศึกษา"
- ต้องรัน `update_departments.php` เพื่ออัพเดตฐานข้อมูลก่อนใช้งาน

## 🐛 แก้ไขปัญหา
หากพบปัญหาการแสดงผล:
1. ตรวจสอบว่า XAMPP เปิด Apache และ MySQL แล้ว
2. เปิด `system_check.php` เพื่อตรวจสอบระบบ
3. ตรวจสอบว่ามีสิทธิ์เขียนในโฟลเดอร์ `uploads/staff/`
