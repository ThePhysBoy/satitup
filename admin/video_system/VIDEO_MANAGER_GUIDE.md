# 📹 คู่มือระบบจัดการวิดีโอแบบง่าย

## ✨ ฟีเจอร์หลัก

### 🎯 ระบบอัตโนมัติ
- ✅ **สร้างตารางอัตโนมัติ** - ถ้าตารางไม่มี ระบบจะสร้างให้เอง
- ✅ **ดึง YouTube ID อัตโนมัติ** - แค่วางลิงก์ ระบบจะหา ID ให้เอง
- ✅ **แสดงภาพตัวอย่าง** - เห็น thumbnail ทันทีเมื่อใส่ลิงก์

### 📝 ฟอร์มง่ายๆ แค่ 3 ช่อง
1. **ชื่อวิดีโอ** - ชื่อที่จะแสดงบนเว็บไซต์
2. **ลิงก์ YouTube** - คัดลอกมาจาก YouTube
3. **คำอธิบาย** - อธิบายสั้นๆ (ไม่บังคับ)

---

## 🚀 วิธีใช้งาน

### 1️⃣ เข้าสู่ระบบ
1. Login ที่: `http://localhost/satitup/admin/login.php`
2. ใช้ Username: `admin` Password: `admin1234`

### 2️⃣ เข้าหน้าจัดการวิดีโอ
- **URL:** `http://localhost/satitup/admin/video_system/simple_video_manager.php`

### 3️⃣ เพิ่มวิดีโอใหม่
1. กรอก **ชื่อวิดีโอ** ที่ต้องการแสดง
2. วาง **ลิงก์ YouTube** (ระบบรองรับทุกรูปแบบ)
   - `https://www.youtube.com/watch?v=xxxxx`
   - `https://youtu.be/xxxxx`
   - `https://www.youtube.com/embed/xxxxx`
3. ใส่ **คำอธิบาย** (ถ้าต้องการ)
4. ✅ ติ๊ก **"ตั้งเป็นวิดีโอแนะนำ"** ถ้าต้องการให้แสดงเด่น
5. คลิก **"เพิ่มวิดีโอ"**

### 4️⃣ แก้ไขวิดีโอ
1. คลิกปุ่ม **"แก้ไข"** ในตารางรายการวิดีโอ
2. แก้ไขข้อมูลตามต้องการ
3. คลิก **"บันทึกการแก้ไข"**

### 5️⃣ ลบวิดีโอ
1. คลิกปุ่ม **"ลบ"** ในตารางรายการวิดีโอ
2. ยืนยันการลบ

## 💡 Tips & Tricks

### ✨ การหาลิงก์ YouTube
1. เปิดวิดีโอใน YouTube
2. คลิกปุ่ม **"แชร์"** ใต้วิดีโอ
3. คัดลอกลิงก์ที่ได้

### 🌟 วิดีโอแนะนำ
- มีได้แค่ 1 วิดีโอ ณ เวลาหนึ่ง
- วิดีโอนี้จะแสดงเด่นในหน้าแรก
- เมื่อเลือกใหม่ วิดีโอเก่าจะถูกยกเลิกอัตโนมัติ

### 📸 ภาพตัวอย่าง
- ดึงมาจาก YouTube อัตโนมัติ
- ถ้าไม่แสดง = ลิงก์ผิด
- ตรวจสอบลิงก์อีกครั้ง

## 🔧 การแก้ปัญหา

### ❌ ลิงก์ YouTube ไม่ถูกต้อง
- ตรวจสอบว่าเป็นลิงก์จาก YouTube จริง
- ลองคัดลอกใหม่จากปุ่มแชร์

### ❌ ภาพไม่แสดง
- รอสักครู่ให้โหลด
- ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต

### ❌ Login ไม่ได้
1. ไปที่ `http://localhost/satitup/admin/reset_password.php`
2. ระบบจะ reset password ให้ใหม่

## 📊 ข้อมูลทางเทคนิค

### Database Tables
```sql
- video_categories (หมวดหมู่)
- videos (วิดีโอ)
```

### ฟิลด์หลักในตาราง videos
- `id` - รหัสวิดีโอ
- `title` - ชื่อวิดีโอ
- `description` - คำอธิบาย
- `youtube_id` - รหัสวิดีโอจาก YouTube
- `youtube_url` - ลิงก์เต็ม
- `featured` - สถานะวิดีโอแนะนำ
- `views` - จำนวนการดู
- `created_at` - วันที่สร้าง
