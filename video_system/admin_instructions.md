# คู่มือการใช้งานระบบวิดีโอสำหรับผู้บริหาร

## 📋 สรุปข้อมูลที่ถูกสร้างในระบบ

### 1. หมวดหมู่วิดีโอ (10 หมวดหมู่)
- บรรยากาศการเรียนการสอน
- กิจกรรมกีฬา  
- ดนตรีและศิลปะ
- ห้องปฏิบัติการ
- แนะนำโรงเรียน
- ภาษาอังกฤษ
- ผลงานทางวิชาการ
- กิจกรรมวิชาการ
- โครงการ วมว.
- พิธีการและงานสำคัญ

### 2. วิดีโอตัวอย่าง (20 วิดีโอ)
ระบบมีวิดีโอตัวอย่าง 20 รายการ พร้อมข้อมูลครบถ้วน:
- ชื่อวิดีโอ
- รายละเอียด
- หมวดหมู่
- จำนวนการดู (ตัวเลขสมจริง)
- วันที่จัดกิจกรรม

**⭐ วิดีโอแนะนำ (Featured):** "แนะนำโรงเรียนสาธิตมหาวิทยาลัยพะเยา ปีการศึกษา 2567"

## 🚀 การใช้งานเบื้องต้น

### 1. ดูวิดีโอในหน้าเว็บไซต์
- **Video Quick Links:** http://localhost/satitup/video_quick_links.php
- **All Videos:** http://localhost/satitup/video_system/all_videos.php

### 2. จัดการวิดีโอผ่าน Admin Panel
- **URL:** http://localhost/satitup/admin/video_system/
- **Username:** admin
- **Password:** [รหัสผ่านที่ตั้งไว้]

### 3. การเปลี่ยน YouTube ID
1. เข้าสู่ระบบ Admin Panel
2. คลิกที่ "แก้ไข" ในวิดีโอที่ต้องการ
3. เปลี่ยน YouTube ID เป็น ID จริงจาก YouTube
   - ตัวอย่าง: `dQw4w9WgXcQ` (จาก URL: youtube.com/watch?v=dQw4w9WgXcQ)
4. บันทึกการเปลี่ยนแปลง

## ⚠️ หมายเหตุสำคัญ

1. **YouTube ID ปัจจุบันเป็นตัวอย่าง** 
   - ใช้ placeholder (xxxxxxxxxxx, yyyyyyyyyyy, ฯลฯ)
   - ต้องเปลี่ยนเป็น ID จริงก่อนใช้งาน

2. **การเพิ่มวิดีโอจริง**
   - คัดลอก YouTube URL จากช่อง YouTube ของโรงเรียน
   - วางใน Admin Panel
   - ระบบจะดึง ID อัตโนมัติ

3. **การตั้งค่าวิดีโอแนะนำ**
   - สามารถเลือกวิดีโอใดก็ได้เป็น Featured
   - จะแสดงเด่นในหน้าแรก
   - มีได้เพียง 1 วิดีโอ ณ เวลาใดเวลาหนึ่ง

## 🔧 การ Reset ข้อมูล

หากต้องการเริ่มใหม่:
1. เข้าที่: http://localhost/satitup/video_system/reset_and_setup.php
2. ระบบจะล้างข้อมูลเดิมและสร้างข้อมูลตัวอย่างใหม่

## 📞 ติดต่อสอบถาม

หากมีปัญหาการใช้งาน:
1. ตรวจสอบว่า Apache และ MySQL ทำงานอยู่
2. ดูหน้าทดสอบระบบ: http://localhost/satitup/test_video_system.php
3. ตรวจสอบ error log ใน XAMPP Control Panel
