# ระบบ Video Quick Links

ระบบนี้ใช้สำหรับจัดการและแสดงวิดีโอกิจกรรมต่างๆ ของโรงเรียนสาธิตมหาวิทยาลัยพะเยา โดยใช้วิดีโอจาก YouTube

## คุณสมบัติหลัก

1. **หน้าแสดงวิดีโอ Quick Links**
   - แสดงวิดีโอแนะนำ (Featured) ขนาดใหญ่
   - แสดงวิดีโอล่าสุด 3 รายการ
   - ลิงก์ไปยังหน้าแสดงวิดีโอทั้งหมด

2. **หน้าแสดงวิดีโอทั้งหมด**
   - แสดงวิดีโอตามหมวดหมู่
   - ค้นหาวิดีโอ
   - แชร์วิดีโอไปยังโซเชียลมีเดีย

3. **หน้าแสดงรายละเอียดวิดีโอ**
   - เล่นวิดีโอจาก YouTube
   - แสดงรายละเอียดวิดีโอ
   - แสดงวิดีโอที่เกี่ยวข้อง
   - แชร์วิดีโอไปยังโซเชียลมีเดีย

4. **ระบบจัดการวิดีโอสำหรับแอดมิน**
   - เพิ่ม/แก้ไข/ลบวิดีโอ
   - ตั้งค่าวิดีโอแนะนำ (Featured)
   - จัดการหมวดหมู่วิดีโอ

## โครงสร้างไฟล์

```
video_system/
├── all_videos.php           # หน้าแสดงวิดีโอทั้งหมด
├── video_detail.php         # หน้าแสดงรายละเอียดวิดีโอ
├── search_videos.php        # หน้าค้นหาวิดีโอ
├── css/
│   └── video-styles.css     # CSS สำหรับหน้าแสดงวิดีโอ
├── database/
│   └── video_tables.sql     # โครงสร้างฐานข้อมูล
└── includes/
    ├── db_config.php        # ไฟล์เชื่อมต่อฐานข้อมูล
    └── video_functions.php  # ฟังก์ชันสำหรับระบบวิดีโอ
```

```
admin/video_system/
├── index.php                # หน้าจัดการวิดีโอ
├── add_video.php            # หน้าเพิ่มวิดีโอใหม่
├── edit_video.php           # หน้าแก้ไขวิดีโอ
└── css/
    └── video-admin.css      # CSS สำหรับหน้าแอดมิน
```

## การติดตั้ง

1. นำเข้าโครงสร้างฐานข้อมูลจากไฟล์ `database/video_tables.sql`
2. ตรวจสอบการเชื่อมต่อฐานข้อมูลในไฟล์ `includes/db_config.php`
3. เพิ่มลิงก์เมนูในหน้าแอดมินโดยเพิ่มโค้ดต่อไปนี้ในไฟล์ `admin/includes/sidebar.php`:

```php
<li class="nav-item">
    <a class="nav-link" href="../admin/video_system/index.php">
        <i class="fas fa-video me-2"></i> จัดการวิดีโอ
    </a>
</li>
```

## การใช้งาน

### การเพิ่มวิดีโอใหม่

1. เข้าสู่ระบบแอดมิน
2. ไปที่เมนู "จัดการวิดีโอ"
3. คลิกปุ่ม "เพิ่มวิดีโอใหม่"
4. กรอกข้อมูลวิดีโอ:
   - ชื่อวิดีโอ
   - URL ของ YouTube
   - หมวดหมู่
   - วันที่จัดกิจกรรม (ถ้ามี)
   - คำอธิบายวิดีโอ
   - ตั้งเป็นวิดีโอแนะนำ (ถ้าต้องการ)
5. คลิกปุ่ม "บันทึกข้อมูล"

### การตั้งค่าวิดีโอแนะนำ

1. ไปที่หน้าจัดการวิดีโอ
2. คลิกปุ่มรูปดาว (⭐) ที่วิดีโอที่ต้องการตั้งเป็นวิดีโอแนะนำ

### การแก้ไขวิดีโอ

1. ไปที่หน้าจัดการวิดีโอ
2. คลิกปุ่มแก้ไข (✏️) ที่วิดีโอที่ต้องการแก้ไข
3. แก้ไขข้อมูลตามต้องการ
4. คลิกปุ่ม "บันทึกการเปลี่ยนแปลง"

### การลบวิดีโอ

1. ไปที่หน้าจัดการวิดีโอ
2. คลิกปุ่มลบ (🗑️) ที่วิดีโอที่ต้องการลบ
3. ยืนยันการลบวิดีโอ

## หมายเหตุ

- ระบบนี้ใช้วิดีโอจาก YouTube เท่านั้น
- วิดีโอแนะนำ (Featured) จะแสดงในส่วนวิดีโอแนะนำบนหน้าแรก
- วิดีโอล่าสุดจะแสดงในส่วนวิดีโอล่าสุดบนหน้าแรก
- การเพิ่มจำนวนการดูวิดีโอจะเพิ่มเมื่อมีการเข้าชมหน้ารายละเอียดวิดีโอ

## การพัฒนาในอนาคต

- เพิ่มระบบการจัดการหมวดหมู่วิดีโอ
- เพิ่มระบบการจัดการแพลยลิสต์
- เพิ่มระบบการแสดงความคิดเห็น
- เพิ่มระบบการจัดอันดับวิดีโอยอดนิยม
